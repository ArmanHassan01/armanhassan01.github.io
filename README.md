# Md. Arman Hassan — Academic Research Portfolio

Static research portfolio built for GitHub Pages.

## Main editable file
`js/portfolio-data.js`

## Quick local preview
You can double-click `index.html`. For the best preview, use a local web server such as VS Code Live Server.

## GitHub Pages
Publish from the `main` branch and `/(root)` folder in **Settings → Pages**.

See `CONTENT_GUIDE.md` for editing and analytics instructions.
