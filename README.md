# Md. Arman Hassan — Academic Research Portfolio

Static GitHub Pages portfolio built with HTML, CSS, and JavaScript.

## Main editing file

`js/portfolio-data.js`

## Site structure

- `index.html` — concise homepage
- `research.html?id=...` — reusable research detail page
- `project.html?id=...` — reusable engineering project detail page
- `privacy.html` — analytics/privacy note
- `css/style.css` — styling and animations
- `js/app.js` — homepage renderer
- `js/detail.js` — research/project detail-page renderer + image lightbox
- `js/analytics.js` — GA4 integration
- `images/` — portfolio visuals
- `videos/` — optional project videos
- `documents/` — CV and downloadable documents

See `CONTENT_GUIDE.md` for editing instructions.
